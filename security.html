Security & Zero-Egress Architecture (Runs on Atlassian)

Last Reviewed: 2026-11-16

Zero External Egress Guarantee: BelegSight declares zero permissions.external endpoints in its Atlassian Forge manifest. Supplier invoices, IBANs, tax IDs, and line items never leave Atlassian's hosted cloud boundary.

1. Compute & Storage Isolation

  • 100% Hosted on Atlassian Forge: All XML parsing, PDF/A-3 stream extraction, EN 16931 math verification, DATEV EXTF formatting, and SEPA pain.001 XML generation execute ephemerally inside Atlassian's isolated Node.js 22 V8 sandbox.
  • No Vendor Servers or Databases: BelegSight operates zero external backend servers, zero third-party databases, zero analytics trackers, and zero external AI/LLM API calls.
  • Data Residency Inheritance: Workspace configuration stored in Forge Encrypted App Storage and audit metadata stored in Jira Issue Entity Properties remain strictly inside your Jira Cloud tenant's Atlassian data residency region (e.g., EU / Frankfurt).

2. Input Hardening & Fraud Controls

  • XXE & Entity-Expansion Blocking: DTD <!ENTITY> and external SYSTEM / PUBLIC DOCTYPE declarations are deterministically rejected prior to XML parsing.
  • Decompression & Memory Bounds: Attachments exceeding 15 MB and compressed PDF FlateDecode streams exceeding 20 MB output are rejected cleanly to prevent zip-bomb / denial-of-service vectors.
  • Strict Content Security Policy (CSP) & XSS Escaping: All Custom UI views execute external bundled scripts (no inline script evaluation) and HTML-escape every untrusted invoice string.
  • CSV Formula-Injection Defense: DATEV EXTF text fields neutralize leading =, +, -, and @ characters.

3. Vulnerability Disclosure

Security researchers and enterprise security teams may report suspected vulnerabilities to belegsight@gmail.com with subject line [SECURITY] BelegSight. We acknowledge reports within 48 hours.
